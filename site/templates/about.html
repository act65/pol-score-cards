NZ Politician Scorecards

This project aims to provide a fun, data-driven way to assess the performance of New Zealand politicians.

The scores are intended to reflect various aspects of their political behaviour, helping the public make more informed decisions.

Motivation

It bugs me that politicians can get away with saying whatever they want, and there's no way to hold them accountable for their promises, predictions, lies, ... This project is my attempt to change that.

Together, these attributes answer the question: when politician X talks, should I listen?

These attributes were chosen as they allow for a broad assessment of a politician's performance and accountability, while being politically neutral.

While we could extract data about other attributes related to the ... I want to keep this apolitical.

Methodology

The scores are calculated based on the analysis of public statements.

Our data scources are; Hansard, media reports, press releases.

We use LLMs to extract the relevant information from the text, and then apply a set of rules to determine the score for each attribute.
